## Description

Friday is an innovative AI-powered calendar assistant that revolutionizes personal scheduling through intelligent automation and seamless integrations. Built with modern web technologies, it combines natural language processing with calendar management to create a streamlined experience where users can schedule events conversationally, resolve conflicts automatically, and optimize their time with AI-driven suggestions. The application features full Google Calendar synchronization, ensuring users maintain a unified view of their commitments across platforms while prioritizing privacy and security.

## Features

- Natural language event creation allowing users to type commands like "Coffee with Alex tomorrow at 3pm" for instant scheduling
- AI-powered smart scheduling that analyzes patterns and suggests optimal meeting times to eliminate coordination hassles
- Intelligent conflict resolution that detects double-bookings and proposes alternative times automatically
- Google Calendar integration with OAuth authentication for seamless bidirectional synchronization
- Multiple calendar view options including agenda, day, week, and month layouts with responsive design
- Context-aware notifications and reminders that adapt to user habits and traffic conditions
- Dark mode support and modern UI built with shadcn/ui components for an intuitive experience
- End-to-end encryption and privacy-first architecture ensuring data security
