## Description

Metarics is a modern, student-focused club webpage built with Astro, designed to provide easy access to event details, blog posts, and helpful resources for students. The site emphasizes accessibility and user-friendliness, featuring a clean interface for navigating upcoming and past events, with integrated authentication for personalized experiences. Its unique hybrid static/dynamic rendering ensures fast performance while supporting real-time features like search and media embeds.

## Features

- Blog system with MDX-powered posts for detailed event information and references.
- Real-time search functionality using Lunr for quick querying of content.
- Firebase-based authentication for user sign-in, registration, and personalized access.
- Responsive design with Tailwind CSS for seamless viewing on all devices.
- Media previews and embeds, including YouTube videos and image galleries.
- RSS feed support for subscribing to blog updates.
- Serverless deployment on Vercel for scalable, high-performance hosting.

## What I Learnt

- Implementing hybrid static and server-side rendering with Astro for optimal performance and SEO.
- Integrating Firebase for authentication and potential real-time database features in a static site context.
- Managing content with MDX and Astro collections for scalable blogging and dynamic routing.
- Building efficient client-side search using Lunr for fast, offline-capable querying.
- Designing responsive UIs with Tailwind CSS and custom components for a polished user experience.
- Best practices for serverless deployment on Vercel, including adapter configuration.
