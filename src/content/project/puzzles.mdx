## Description

This is an interactive puzzle application designed to challenge and train the brain through a variety of mini-games, including memory card matching, logical reasoning, speed-based tasks, analytical puzzles, and even a ping pong game. Users can solve riddles stored in Firebase, track their progress, and aim to complete all challenges. The app features user authentication and analytics, making it a comprehensive platform for mental stimulation and skill improvement.

## Features

- Multi-Game Variety: Offers distinct games like memory card flipping, logical puzzles, speed challenges, analytical tasks, and ping pong for diverse brain training.
- Riddle-Based Main Puzzle: Features a series of riddles (e.g., fruit and vegetable clues) that users solve, with progress tracked in real-time via Firebase.
- User Authentication: Supports login and signup functionality for personalized experiences.
- Progress Tracking: Stores and updates user answers and completion status in a Firebase database.
- Responsive UI: Built with Tailwind CSS for a clean, grid-based interface, including flip-able cards in the memory game.
- Analytics Integration: Includes user analytics and progress visualization components.
