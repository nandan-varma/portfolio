## Description

Pod is a modern web-based podcast application built with Next.js and Supabase, enabling users to upload, discover, and stream podcasts seamlessly. The app features user authentication, a search functionality for finding podcasts by name, and an integrated audio player for uninterrupted listening. It provides a clean, responsive interface for podcast enthusiasts to manage and enjoy their favorite content, with support for direct file uploads or URL-based additions to the library.

## Features

- User Authentication: Secure login and logout using Supabase Auth, protecting access to podcast management features.
- Podcast Upload: Upload audio files (.m4a, .mp4) directly to Supabase Storage or add via external URLs, automatically calculating duration.
- Search Functionality: Real-time search through podcast titles using Supabase's text search capabilities, displaying results in a responsive table.
- Audio Playback: Integrated HTML5 audio player with controls for play, pause, and navigation, managed via React Context for state.
- Responsive UI: Built with Tailwind CSS and Radix UI components for a modern, accessible interface across devices.
- Data Management: Server-side rendering with Next.js for optimal performance, storing podcast metadata in Supabase PostgreSQL.
