## Description

This is a personal portfolio website for Nandan Varma, designed to showcase software engineering projects, blog posts, and interactive experiences. Built with modern web technologies, it features a responsive design with engaging animations and a clean, minimalist aesthetic to highlight creative coding work. The site includes sections for projects, writing, and contact, serving as both a professional showcase and a playground for experimental features like a car game and live Python code execution.

## Features

- Project Showcase: Displays various software projects with detailed descriptions, technologies used, and links to repositories or demos
- Blog Section: Features MDX-powered articles on topics like databases, fitness, and productivity, with formatted dates and content layouts
- Interactive Elements: Includes a car racing game, live Python code editor with syntax highlighting, and dynamic background animations
- Responsive Design: Utilizes Tailwind CSS for mobile-first layouts and glass card effects for visual appeal
- SEO and Performance: Integrates sitemap generation, RSS feeds, and optimized images for fast loading and discoverability
- Open Graph Images: Automatically generates social media preview images for blog posts and project pages

## What I Learnt

- Implementing complex animations and 3D effects using Three.js and custom canvas controllers for interactive backgrounds
- Building content-driven sites with Astro and MDX for efficient static generation and dynamic routing
- Integrating CodeMirror for live code editing and Pyodide for running Python in the browser
- Optimizing web performance with modern build tools, image processing, and deployment to platforms like Vercel and Cloudflare
- Designing responsive UI components with Tailwind CSS and React, focusing on accessibility and user experience

## Built With

- [Astro](https://astro.build) - Static site generator
- [React](https://reactjs.org) - UI library for interactive components
- [Tailwind CSS](https://tailwindcss.com) - Utility-first CSS framework
- [Three.js](https://threejs.org) - 3D graphics library
- [CodeMirror](https://codemirror.net) - Code editor component
- [Pyodide](https://pyodide.org) - Python runtime in the browser
- [MDX](https://mdxjs.com) - Markdown with JSX support
