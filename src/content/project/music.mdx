## Description

This modern music streaming app is a progressive web application (PWA) that enables users to search and stream a vast library of songs, albums, artists, and playlists. It offers offline listening capabilities, persistent audio playback with queue management, and seamless device integration. Leveraging the JioSaavn API for music data, the app provides a responsive, mobile-first design optimized for both desktop and mobile experiences.

## Features

- Global search across songs, albums, artists, and playlists with real-time results
- Persistent audio player featuring queue management, playback controls, and media session integration
- Offline mode with downloads to IndexedDB for uninterrupted listening without connectivity
- Installable PWA including service worker caching for static assets and background sync
- Responsive design with mobile-first approach and desktop optimizations
- Robust audio playback using HTML5 Audio API with error handling and volume controls
- Detailed music metadata fetching and pagination via external API integration

## What I Learnt

- Implementing advanced React patterns such as splitting contexts to minimize re-renders for better performance
- Developing PWA features including service workers, offline storage with IndexedDB, and web app manifest
- Managing complex audio playback with HTML5 Audio API, Media Session API, and comprehensive error handling
- Integrating with external REST APIs for data fetching, pagination, and state management
- Utilizing TanStack Query for efficient caching and synchronization of API responses
- Building responsive, accessible UI components using Radix UI primitives and Tailwind CSS
