## Description

Bingo Game is a web-based multiplayer bingo application that allows users to host or join real-time games with friends. Players can create a game room, share the unique game ID, and compete in turn-based bingo matches where marking numbers leads to scoring bingo lines. The app leverages Firebase for seamless real-time synchronization, ensuring all players see live updates without page refreshes, making it ideal for social gaming sessions.

## Features

- Real-time multiplayer gameplay: Host or join games instantly with Firebase-powered synchronization for live board updates and turn management.
- Interactive bingo board: 5x5 grid with clickable numbers, visual marking, and automatic scoring based on completed lines.
- Game state management: Tracks player turns, marked numbers, and detects winners when a player achieves 5 bingo lines.
- Simple room system: Unique game IDs for private rooms, allowing players to enter names and join specific sessions.
- Responsive UI: Built with Next.js and React for a clean, user-friendly interface across devices.
- Persistent game data: Uses Firebase Realtime Database to store and update game states reliably.
