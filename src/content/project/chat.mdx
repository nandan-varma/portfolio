## Description

This is a real-time chat application developed as a personal challenge to explore encryption technologies and modern web development practices. The app enables users to create and join password-protected chat rooms for secure, instantaneous messaging with friends and colleagues. Featuring end-to-end encryption powered by the Web Crypto API, it ensures message privacy while providing a smooth, responsive user experience across devices.

## Features

- Real-time messaging: Instant message delivery and updates using Firebase Realtime Database
- Chat rooms: Create and join multiple conversation rooms with unique IDs
- End-to-end encryption: AES-GCM encryption for message security using browser's Web Crypto API
- Password-protected rooms: Optional password protection with hashed verification
- User authentication: Secure sign-in and sign-out with Firebase Authentication
- Responsive UI: Clean, modern interface built with shadcn/ui and Tailwind CSS
- Auto-scrolling chat: Automatic scrolling to latest messages for seamless conversation flow
