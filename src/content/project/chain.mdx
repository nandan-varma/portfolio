## Description

Chain Reaction 3D is an immersive web-based implementation of the classic Chain Reaction board game, featuring stunning 3D graphics and smooth animations. Players take turns placing colored orbs on a grid-based board, where cells explode when reaching their critical mass, spreading orbs to adjacent cells in a chain reaction. The game continues until one player eliminates all opponent orbs, creating dynamic and strategic gameplay with visual flair.

## Features

- 3D Interactive Board: Fully interactive 3D game board built with Three.js and React Three Fiber, allowing players to click cells to place orbs
- Animated Explosions: Spectacular explosion effects when cells reach critical mass, with orbs cascading to adjacent cells in smooth animations
- Turn-Based Gameplay: Clean turn indicator showing current player and game status, with automatic player switching
- Hover Effects: Visual feedback on valid moves with cell highlighting and color changes
- Real-Time Animations: Fluid orb movements, floating animations, and color transitions throughout gameplay
- Victory Detection: Automatic win condition checking and clear victory announcements
- Responsive UI: Modern interface with dark theme, using Tailwind CSS and Radix UI components
