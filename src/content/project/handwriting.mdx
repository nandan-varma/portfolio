## Description

This web application transforms plain text into PDF documents that mimic authentic handwriting, perfect for creating personalized assignments and notes. Users can input text, customize various styling options like font size, color, and line spacing, and instantly preview or download the generated PDF with a natural handwritten appearance achieved through randomized font variations and subtle line irregularities.

## Features

- Text Input Interface: A resizable textarea for entering and editing text content.
- Customizable Controls: Advanced settings including font size, line height, margins, letter spacing, and text color via an intuitive popover interface.
- Preset Configurations: Quick-select presets (small, medium, large) for common formatting needs.
- Real-Time Preview: Embedded PDF viewer for instant preview of the handwritten output.
- Download Functionality: One-click PDF download with customizable filename.
- Responsive Layout: Horizontal resizable panels for optimal workspace management.
- Handwriting Simulation: Randomized font selection per character and slight line variance for authentic handwritten look.
