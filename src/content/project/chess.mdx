## Description

Chess Online is a web-based chess platform built with Next.js, offering multiple game modes including local play, AI challenges, and friend matches. Players can enjoy a fully interactive chess experience with drag-and-drop moves, move validation, and game state management. The app provides a responsive interface with real-time feedback for checkmates, draws, and invalid moves, making it accessible for both casual and competitive players.

## Features

- Interactive chessboard with drag-and-drop piece movement and visual move highlights
- Multiple game modes: local play against yourself, versus AI opponent, and online friend matches
- Undo, redo, and reset functionality for flexible gameplay
- Pawn promotion support with user prompts for piece selection
- Game status notifications via toasts for checkmates, draws, and invalid moves
- Responsive design with dark theme support for better user experience
- Integration with chess engines for AI opponent logic

## What I Learnt

- Implementing real-time chess game logic using the chess.js library for move validation and FEN notation
- Managing complex state in React with hooks for game history, AI responses, and UI interactions
- Integrating third-party chessboard UI components (chessboardjsx) with custom styling and event handling
- Handling asynchronous operations like AI move delays to simulate realistic gameplay
- Building modular React components with TypeScript for type safety in game mechanics
- Utilizing Firebase for potential authentication and data persistence in multiplayer scenarios
