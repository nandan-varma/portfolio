## Description

RepLog is a minimalistic workout logging app designed for fitness enthusiasts to track their exercises and progress efficiently. It integrates the Free Exercise DB to provide a comprehensive library of exercises, allowing users to log sets, reps, weight, and duration for each workout. The app features an intuitive onboarding process, bookmarking for favorite exercises, and a clean UI built for mobile devices, making it easy to maintain a consistent fitness routine without unnecessary clutter.

## Features

- Workout Logging: Log detailed workout sessions including sets, reps, weight, and duration for each exercise.
- Exercise Library: Access a vast database of exercises from the Free Exercise DB, categorized by type, equipment, and difficulty level.
- Bookmarking System: Bookmark favorite exercises for quick access and personalized workout planning.
- Onboarding Flow: Guided setup process to collect user details like age, height, weight, and fitness goals.
- Calendar Integration: View workout history and stats on a calendar interface for tracking progress over time.
- Filtering and Search: Filter exercises by category, equipment, or search queries to find specific workouts.
- Dark Mode Support: Automatic theme switching based on device settings for comfortable viewing.
- Offline Support: Local SQLite database ensures workouts can be logged without internet connectivity.
